# v0.30 成本参考值

## 产品边界

每日和每月成本值是运营参考，不是预算上限，也不会把调用停在门口。分析和转写
在配置参考值后仍照常调用服务商；参考值用于设置页和运营侧观察预计成本。

成本账本是追加式的调用后估算记录，单位来自渠道的成本元数据。它不是发票、扣款
或任何形式的 Billing Record。账本记录失败不会让已经成功提交的作业失败。

## API

流水线设置使用以下字段：

- `daily_cost_guide`
- `monthly_cost_guide`

读取设置时仍可接受一次旧版本的 `daily_budget` 和 `monthly_budget` 输入，服务会将其
解释为对应的成本参考值；新的响应只返回新字段。

成本汇总使用：

- `today_estimate`
- `month_estimate`

历史作业中已经持久化的 `budget_exhausted` 延迟或失败类别继续可读，但 v0.30 的
流水线不会再生成它。

## 运维含义

参考值不会自动释放、暂停或推迟作业。需要控制调用并发、通道健康和重试行为时，应
使用对应的 Provider Channel 和流水线重试配置；成本参考只回答“预计已经花了多少”。
