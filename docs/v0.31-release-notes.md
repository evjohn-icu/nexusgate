## What Changed

The audit-repair round is listed first because the rename is the first change
an existing install meets; the release-preparation round follows.

### Audit-repair round (35 commits after the audit baseline)

- **The project is now `nexusgate`.** It was renamed `timingdex` →
  `nexusslate` → `nexusgate`, and the binary, Go module path, and `skills/`
  directory were renamed with it. Commands, import paths, and the skill name
  are all different from an install that predates the rename.
- **SMB discovery and the mount wizard were repaired and finished.** LAN
  discovery works again, an XSS and a shell injection were closed, and share
  names are classified with the SMB-legal character set. The Windows and
  Unraid paths are complete; root warnings are localized in all five languages
  and a deployment declares its own platform. Discovery diagnostics and the
  scan wait were rewritten around what the operator can do next, `IPC$` is no
  longer enumerated, and the sidebar status strip no longer clips in four of
  the five languages.
- **Scanning, staging, and the source cache were reworked.** A scan no longer
  re-reads the whole library: an asset whose size and mtime are unchanged
  reuses its fingerprint. `cache/sources` gained a byte cap and an LRU
  evictor, plus four gaps an audit found in them. The Worker's source cache
  defaults to 256 GiB and can be set at enroll time; the Hub's default stays
  unbounded. The two sides default in opposite directions on purpose, and each
  default is documented where it is set.
- **One unreadable file no longer freezes a library.** A single file that
  failed to fingerprint used to mark its whole root unavailable, so every
  enqueue failed while the scan still reported success: on a real NAS share,
  4792 files and 985 GiB produced `discovered=4339 errors=1`, exit code 0, and
  zero jobs and artifacts. Root reachability and scan completeness are now
  separate decisions, and root scans print `queued=N` so a scan that creates no
  work is visible.
- **Apple Log previews have a way in, and a rejected file has a name.** The
  preview LUT was documented as per-install configuration, but all five
  construction sites passed an empty string, so every Apple Log clip lost its
  thumbnail, proxy, and audio. `preview_lut_path`, `NEXUSGATE_PREVIEW_LUT_PATH`,
  and `worker enroll --preview-lut` now supply it; no LUT ships with the
  product, so the setting only points at the operator's own copy, and empty
  still means the same explicit refusal. The same change adds
  `media.ErrProbeRejected`, which marks the one `ffprobe` outcome that is a
  verdict on the file and maps it to `JobFailureCategoryMediaDecode` — an
  identity whose comment had read "No sentinel produces it yet" since it was
  written. It is deliberately **not** marked permanent, because `exit status 1`
  cannot be told apart from a file that is still being copied.

### Release-preparation round

- P0 CI work makes browser smoke repository-owned, deterministic, HTTPS-aware,
  tool-pinned, and blocking; Windows command fixtures use a cross-platform
  helper instead of POSIX-only shell files.
- Search v2 batches transcript evidence, speech-phrase validation, and final
  context lookups, adds the ordinal index, preserves `query_hash` wire bytes,
  and avoids quadratic full-scan candidate sorting.
- HTTP routes are grouped through a typed, auditable inventory. The browser
  shell separates Core navigation from Advanced / Operator links while keeping
  existing capabilities and paths.
- The release target is centralized in `VERSION`; Docker, Compose, Unraid, and
  native builds receive the same version metadata. The offline relevance corpus
  and baseline schema are checked in; measured SQLite and relevance results
  remain release gates.

warm/fresh; 1k and 10k are approximate medians of three samples, while 100k is
one stable sample.

### Relevance baseline

The deterministic offline set contains 32 explicitly language-labelled
Chinese, English, and mixed-language queries. Measured results are
Recall@20 `0.789`, Precision@10 `0.094`, nDCG@10 `0.725`, empty-result rate
`0.250`, expected-empty accuracy `0.812`, evidence correctness `0.800`,
evidence precision `0.909`, intent match `22/32`, and zero judged hard-negative
hits. All of these values participate in the checked-in regression gate.
