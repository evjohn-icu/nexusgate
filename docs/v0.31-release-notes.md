# v0.31.0-alpha Release Notes

Status: repository preparation and release evidence are recorded. The target
is declared in the root `VERSION` file, but this worktree has not created a
tag, GitHub release, or container image.

Baseline: `dc88861bf3078bc9f29ad4b60dd579b43dece6f9` (`main`). The finding-level
audit is in [`v0.31-scope-audit.md`](v0.31-scope-audit.md). This document is the
release handoff: measured values retain the precision reported by their runs,
and remaining publication gates are listed below.

## What Changed

- P0 CI work makes browser smoke repository-owned, deterministic, HTTPS-aware,
  tool-pinned, and blocking; Windows command fixtures use a cross-platform
  helper instead of POSIX-only shell files.
- Search v2 batches transcript evidence, speech-phrase validation, and final
  context lookups, adds the ordinal index, preserves `query_hash` wire bytes,
  and avoids quadratic full-scan candidate sorting.
- HTTP routes are grouped through a typed, auditable inventory. The browser
  shell separates Core navigation from Advanced / Operator links while keeping
  existing capabilities and paths.
- The release target is centralized in `VERSION`; Docker, Compose, Unraid, and
  native builds receive the same version metadata. The offline relevance corpus
  and baseline schema are checked in; measured SQLite and relevance results
  remain release gates.

### SQLite scale

The measured host was Intel N100 (4 CPUs, 7.5 GiB RAM), Linux amd64, Go
1.26.4, `modernc.org/sqlite` v1.56, WAL with `synchronous=NORMAL`. Values are
warm/fresh; 1k and 10k are approximate medians of three samples, while 100k is
one stable sample.

| scenario | 1k | 10k | 100k |
| --- | ---: | ---: | ---: |
| lexical | 5.37/8.32 ms | 49.81/54.63 ms | 542.16/534.30 ms |
| hybrid | 27.77/42.55 ms | 268.41/364.70 ms | 3.688/3.677 s |
| fact (evidence) | 80.68/97.12 ms | 739.40/830.04 ms | 7.495/8.377 s |
| context | 92.73/97.95 ms | 740.56/830.20 ms | 7.485/8.382 s |
| embedding | 17.72/25.67 ms | 197.12/200.65 ms | 2.209/2.199 s |

Warm 100k allocation results were lexical `65,760 B / 1,139 allocs`, hybrid
`1,054,380,944 B / 12,491,212 allocs`, fact `1,717,258,616 B / 18,576,319
allocs`, context `1,717,325,088 B / 18,578,048 allocs`, and embedding
`720,872,960 B / 6,090,107 allocs`. The 500k run was deferred due to
resource/runtime cost; no ANN implementation is claimed.

### Relevance baseline

The deterministic offline set contains 32 explicitly language-labelled
Chinese, English, and mixed-language queries. Measured results are
Recall@20 `0.789`, Precision@10 `0.094`, nDCG@10 `0.725`, empty-result rate
`0.250`, expected-empty accuracy `0.812`, evidence correctness `0.800`,
evidence precision `0.909`, intent match `22/32`, and zero judged hard-negative
hits. All of these values participate in the checked-in regression gate.
