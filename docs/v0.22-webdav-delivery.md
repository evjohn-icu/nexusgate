# WebDAV 素材交付（v0.22+）

> 现状同步：Hub 默认启用 HTTPS（`hub_tls.mode=auto`），挂载 URL 使用
> `https://`。WebDAV 账号、空间与软链全部由管理员/运营者经 admin API
> （`/api/v1/admin/webdav/...`）创建；当前 MCP 工具集是六个只读工具
> （`inspect_library`、`search_shots`、`get_timeline`、`get_transcript`、
> `get_asset`、`get_shot`），**不包含** `request_source_media`——agent 不经 MCP
> 请求原始素材，交付由运营者完成。本页其余内容保持 v0.22 的历史叙述。

按需 WebDAV 空间把素材字节交付给剪辑软件（Final Cut Pro 等）。空间初始为空，
**只有被显式软链的素材才可见**；字节从 NAS 原文件流式读取，不复制、不落临时
目录，且客户端永远看不到真实路径。

## 工作流

```
编辑 agent ──MCP（只读）──▶ 搜素材（search_shots），指出需要的 asset
管理员/运营者 ──admin API──▶ 建空间 → 软链 asset 进空间 → 返回 /spaces/{id}/assets/{asset}/...
剪辑软件 ──WebDAV(Basic Auth)──▶ 挂载空间（https）→ 按需取片
```

1. 管理员建一个**交付账号**（用户名 + 密码，密码只存 bcrypt 哈希）。
2. 管理员建一个**空间**（每次剪辑会话一个）。
3. 按需把素材软链进空间（original 原片 或 proxy 代理）。
4. 剪辑软件用账号密码挂载 `https://<hub>:<port>/spaces/<id>/`，取片。
5. 会话结束撤销空间——未撤销前空间内路径 404。

## API

| 端点 | 权限 | 说明 |
|---|---|---|
| `POST /api/v1/admin/webdav/accounts` | Hub admin | 建账号 `{username, password}` |
| `GET /api/v1/admin/webdav/accounts` | Hub admin | 账号列表 |
| `DELETE /api/v1/admin/webdav/accounts/{username}` | Hub admin | 删账号 |
| `POST /api/v1/admin/webdav/spaces` | Hub admin | 建空间，返回 `space_id` |
| `POST /api/v1/admin/webdav/spaces/{id}/links` | Hub admin | 软链 `{asset_id, kind: original\|proxy}` |
| `GET /spaces/{id}/...` | WebDAV Basic Auth | 只读取文件（PROPFIND/GET），写拒绝 |

## 安全边界

- **只读**：PUT/MKCOL/RemoveAll 全部拒绝（source-media-readonly 对齐）。
- **路径不泄露**：客户端只见虚拟路径 `/assets/{id}/original.mov`，真实 NAS
  路径只在服务端解析。
- **按需可见**：未软链的素材在空间里 404——暴露面=被请求过的素材，不是全库。
- **密码**：bcrypt 哈希落库，明文不落盘、不进日志。
- **空间撤销**：`DELETE` 或进程重启后空间消失，对应路径 404。

## 客户端挂载

macOS Finder：「连接服务器 → `https://<hub>:8787/spaces/<id>/` → 输入账号密码」，
挂载成卷。Final Cut Pro 的「重新连接媒体」即可指向该卷内的原片。

## 实现

- `internal/webdavspace/`：虚拟 FileSystem（`golang.org/x/net/webdav`）、空间、
  账号（`golang.org/x/crypto/bcrypt`）、Basic Auth Manager。
- `internal/repository/sqlite/webdav_accounts.go`：账号持久化。
- `internal/api/server.go`：管理端点 + `/spaces/` 挂载。
- 依赖：`golang.org/x/net`、`golang.org/x/crypto`。
