# v0.28.2 Worker Setup Path Redaction

## Boundary

The trusted-read worker setup context no longer returns absolute Hub library root
paths. Its `library_roots` entries contain only `id`, while hub URL, TLS details,
fingerprint and available worker binaries remain available to the setup wizard.

Absolute paths are available only from:

```text
GET /api/v1/admin/hub/worker-setup/library-roots
Authorization: Bearer <hub-admin-token>
```

The response is `{ "library_roots": [{ "id": "...", "path": "..." }] }`.
Failures from the library-root repository are returned to the administrator rather
than being converted to an empty list.

## Browser Behavior

The `/worker-setup` page first loads the redacted context without a token. When an
administrator token is present in the page's password field, it then requests the
admin-only detail route and uses the returned paths for the mount labels. The token
is not written to browser storage, URLs, or query parameters.
