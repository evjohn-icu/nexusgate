# v0.5.2 semantic-governance architecture

```text
Gemini / vision analysis
  → raw tag links (always retained)
  → unresolved-tag pool
  → real text embeddings
  → transparent candidate clusters
  → Tag Curator provider
  → pending proposals
  → human review
  → canonical tags + aliases
  → search and repurpose workflows
```

The embedding layer answers only one question: which raw tag strings are
plausibly close enough to review together? It is not a replacement for tag
governance, and it is not a footage ranking system.

The Curator receives bounded input and returns JSON drafts. NexusGate validates
those drafts against the original unresolved-tag set, derives all database IDs
itself, and keeps the existing approval transaction as the only path that can
change canonical mappings.

Library summaries are separate from tag proposals. Their input is a durable
statistics snapshot, so a generated summary can be explained and regenerated
without rereading raw footage. The resulting `summary`, `themes` and
`suitable_for` fields are intended to seed later natural-language repurpose
queries, not to masquerade as facts beyond the observed library.
