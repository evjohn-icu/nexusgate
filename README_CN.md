# Re:Footage

**你有几个 T 的素材，但什么都找不到。这东西是来解决这件事的。**

[English → README.md](README.md)

`Re:Footage` 是产品名；`nexusgate` 是二进制、模块路径和配置命名空间。

---

## 问题在哪

你的硬盘或者 NAS 上躺着好几年的素材。`DJI_0284.MP4`、`A001_C007.mov`、
`IMG_4471.MOV`。你记得里面有个不错的日落航拍，但找它意味着在文件夹里拖四十分钟
进度条——最后多半是放弃，重新去拍一条。

文件名不告诉你片子里有什么，文件夹也不会。唯一能告诉你的办法是看一遍。

## 它做什么

它替你把素材看一遍——**只看一遍**——然后记住。

它读你现有的文件夹（**从不往里写任何东西**），把每条片子切成镜头，建一个能到
单个镜头粒度的索引。然后你用大白话问，它把片子**和时间码**一起给你：

```
"航拍拉远，海岸线，日落"
→ 旅行/DJI_0284.MP4     00:12–00:24    ← 是那个镜头，不只是那个文件
→ 空镜/A001_C007.mov    01:47–02:03
```

全部跑在你自己的机器上。素材一个字节都不出门。

**具体给你的东西：**

- **镜头级检索** —— 画面里有什么、说了什么、元数据，三路一起找。而且带一道
  证据闸：把「这条排名高」和「这条确实有你要的东西」分开。**没把握它会说
  「未知」，不会瞎猜。**
- **代理片和缩略图** —— 只生成一次。哪怕原片是 16 GB 的 ProRes 躺在机械盘上，
  翻库也是秒开。
- **语音转写** —— 按完整短语检索，不是松散关键词。
- **浏览器界面、命令行、HTTP API、MCP 服务** —— 你用哪个都行。

## 它不是什么

先把话说清楚，不然浪费你一晚上：

- **这是 alpha。** 能用，但没做完，而且还会变。
- **别把它暴露到公网。** 它是给你自己的机器或者可信内网用的。真在容器里配出
  那种不安全的组合，Hub 会直接拒绝启动。
- **聪明的那部分需要模型服务。** 扫描、代理片、缩略图、元数据检索、镜头切分
  全是本地的。语音转写和画面理解要调你自己配的服务商——或者你自己跑的本地模型。
  一个都不配也能用：你仍然得到一个能翻、去过重、有代理片的素材库，只是没有
  语义检索。
- **它不是剪辑软件**，也不是素材管理器。它负责**找到**。剩下的交给你的 NLE，
  时间线导出是给这个用的。

## 安装

### Docker —— 最短路径，什么都不用装

```bash
git clone https://github.com/evjohn-icu/nexusgate.git && cd nexusgate
NEXUSGATE_MEDIA_ROOT=/你的/素材目录 docker compose up -d --build hub
```

镜像内部自己编译 Go，也自带 FFmpeg 和 exiftool，所以前置条件的完整清单就是：
Docker。**Windows 上这也是最短的一条路。**

你的素材在容器里的路径是 `/media/library`——下面加素材目录的时候填**这个**，
不是宿主机路径。

### 从源码构建

```bash
git clone https://github.com/evjohn-icu/nexusgate.git && cd nexusgate
go build -o nexusgate ./cmd/nexusgate
```

你需要：

| | |
|---|---|
| **Go** | 1.25.5 —— 这行字要是过时了，以 `go.mod` 为准 |
| **ffmpeg / ffprobe** | 任何较新的版本都行。想要读取限速则需要 5.1+（`-readrate` 在那之前不存在；老版本会跳过这一个设置并告警，而不是让每次转码都失败） |
| **exiftool** | 可选。没有它，拍摄元数据就只剩 ffprobe 能读出来的那些 |

不需要数据库服务，没有 Web 框架，没有前端构建步骤。九个直接依赖，全在
`go.mod` 里。

## 第一次跑

```bash
export NEXUSGATE_DATA_DIR="$PWD/.nexusgate-data"

./nexusgate doctor                     # 缺什么？先按它说的修
./nexusgate root add /你的/素材目录     # 只读。绝不往那里写任何东西
./nexusgate root list                  # 抄下它打印的 root id
./nexusgate root scan <root-id>        # 遍历、算指纹，然后开始处理
./nexusgate serve                      # 起在 https://127.0.0.1:8787
```

然后打开浏览器界面。

**关于 `root scan` 得说一句，第一次跑的人都会被吓到。** 它会先遍历你的库，
然后在**同一条命令里**把整个处理队列抽干。50 个片子的库是几分钟的事；
5000 个片子的 NAS 是**一整夜**的活——它要把每个文件都过一遍网络，还要给每个
转一条代理片。**Ctrl-C 是安全的**：已经做完的不会重做，下次接着上次的进度跑。
盯着它打印的 `queued=`，那才是它真正创造出来的工作量。

之后的扫描很快。大小和 mtime 都没变的文件不会被重读。

所有东西都在 `$NEXUSGATE_DATA_DIR` 底下——数据库、缓存、令牌。**删掉那个目录
就是重置。** 你的素材不受影响，因为从头到尾就没往它旁边写过东西。

### 两个令牌

Hub 第一次启动会生成两个凭据，都是数据目录里的 `0600`：

- **`admin-token`** —— 完全控制权，是你的。**别给 agent**，别写进 Worker 配置，
  别放进浏览器存储。
- **`agent-token`** —— 只读 + 起草。**这个才是给助手的那个。**

在可信内网里，读操作完全不需要令牌，写操作需要。从别的网络来，两者都需要。

## 让 agent 帮你装

这个仓库是**照着「会被 coding agent 读」来写的**，装它正好是适合交给 agent 的活。

```bash
git clone https://github.com/evjohn-icu/nexusgate.git && cd nexusgate
claude   # 或者任何能读文件、能执行命令的 coding agent
```

然后大意这么跟它说：

> 把这个跑起来，素材在 `/我的/素材目录`。先读 `CLAUDE.md`，然后跑
> `nexusgate doctor`，把它报的问题都修掉再开始扫描。

**为什么这条路真的成立、而不是噱头**：仓库根目录的 `CLAUDE.md` 是一份真正的
架构文档——分层图、流水线、以及那些一碰就坏的不变式。而 `nexusgate doctor`
是**照着「让人照它去做」写的**：它会点名缺的二进制、错的目录权限、那个密钥
始终没解析成功的服务商。这两样加起来，agent 手里就有了把你从 clone 送到
「Hub 跑起来了」所需要的全部东西，你不用先去学一遍命令行。

也把话说清楚：**这里没有安装脚本。** agent 读的是跟你一样的文档，跑的是跟你
一样的命令。你买到的是「不用自己动手」，不是别的。

**有两件事要交代它。** 给它 **agent 令牌**，不是 admin 那个。以及——它要是
提议把 Hub 开到公网上，拒绝。

## 装完之后怎么跟 agent 配合

库建好之后，助手可以替你在里面找东西。

**MCP** —— `cmd/nexusgate-mcp` 用 stdio 说 MCP，暴露**六个只读工具**：
`inspect_library`、`search_shots`、`get_shot`、`get_asset`、`get_timeline`、
`get_transcript`。它是你 Hub 的一个**很薄的 HTTP 客户端**：不持有数据库句柄，
也碰不到你的媒体文件。示例配置在 `skills/nexusgate/mcp/.mcp.json.example`，
`plugins/claude` 下还有一个现成的 Claude Code 插件。

**Agent Skill** —— `skills/nexusgate/SKILL.md` 是一份带版本的契约，用于素材调研：
找可复用的镜头、取镜头证据、起草方案。它动手之前会先调
`GET /api/v1/agent/capabilities`，那个接口会声明哪些事出界——方案审批、跑流水线、
服务商密钥、原始媒体路径。**这个声明是由路由本身强制的，不是写在提示词里的承诺。**

**审批权永远在人手里。** agent 可以起草方案，但**批不了**。

## 再往下

上面全是短版本。需要更多的时候：

| | |
|---|---|
| **NAS 和网络共享** | 浏览器界面里有引导式挂载向导，按你的平台生成确切的挂载命令——Linux、macOS、Windows、Unraid——另外还会直接给出 Docker Compose 的具名卷定义 |
| **模型服务商** | 在浏览器 `/providers` 里配。密钥加密存储，**绝不出现在数据库、API、日志或错误信息里** |
| **分布式处理** | 把 Worker 节点配对到 Hub，让转码跑在有显卡的那台机器上——见 `docs/v0.31-deployment.md` |
| **磁盘负载** | 低峰时段窗口、读取限速、缓存容量上限，免得一次扫描把你的 NAS 占满几个小时 |
| **架构** | `CLAUDE.md` —— 分层图、流水线，以及动手改之前值得知道的那些不变式 |
| **其它一切** | `docs/` —— 部署、检索架构、各版本发布说明 |
